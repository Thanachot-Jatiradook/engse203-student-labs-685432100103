# ENGSE203 LAB 04 — React Campus Service Request

Vite + React Campus Service Request Web Application.

## Components & Architecture

- `AppHeader`: Displays application header
- `SummaryPanel`: Shows total, pending, in-progress, and resolved request counts
- `RequestForm`: Controlled form for creating new service requests
- `FilterBar`: Status filtering controls (all, pending, in-progress, resolved)
- `RequestList`: Renders list of service request cards
- `RequestCard`: Individual request card with status update and delete actions

## Run and Build

```bash
npm install
npm run check
npm run dev
npm run build
```
