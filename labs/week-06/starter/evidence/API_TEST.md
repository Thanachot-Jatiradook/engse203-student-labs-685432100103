## ทดสอบว่าข้อมูลอยู่ถาวร (CP08)

| ขั้น | ทำอะไร | ผลที่เห็น |
|---|---|---|
| 1 | POST เพิ่มคำร้องใหม่ | ตอบกลับ 201 Created ได้ ID ใหม่ขึ้นต้นด้วย `REQ-` และ status เป็น `pending` |
| 2 | GET ดูรายการ — เห็นคำร้องใหม่ไหม | เห็นคำร้องใหม่ที่เพิ่งเพิ่มปรากฏในรายการของ `GET /api/requests` |
| 3 | Ctrl+C ปิดเซิร์ฟเวอร์ แล้วเปิดใหม่ | เซิร์ฟเวอร์หยุดทำงาน และเมื่อเริ่มใหม่ด้วย `npm run dev` เซิร์ฟเวอร์โหลดข้อมูลจาก `data/requests.json` |
| 4 | GET ดูรายการอีกครั้ง — คำร้องยังอยู่ไหม | ข้อมูลคำร้องใหม่ยังคงอยู่ครบถ้วนในรายการ ไม่สูญหาย |
